# Cutiepie Deployment Guide

This document provides step-by-step instructions for deploying the Cutiepie application to the Internet Computer and verifying that all features work correctly.

## Pre-Deployment Checklist

- [ ] Backend canister is deployed and running
- [ ] Frontend code is built and ready
- [ ] App domain is set to "Cutiepie" in `frontend/src/appDomain.ts`
- [ ] Hash-based routing is configured in `frontend/src/App.tsx`
